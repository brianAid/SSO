📘 Panduan SSO: React Client + Laravel Resource Server

React Client

1️⃣ Redirect ke login SSO Server:

const CLIENT_ID = "app1";
const REDIRECT_URI = encodeURIComponent("http://localhost:3000/callback");
const STATE = "secureRandomState";

window.location.href = 
  `http://localhost:3000/authorize?client_id=${CLIENT_ID}&redirect_uri=${REDIRECT_URI}&state=${STATE}`;

2️⃣ Di halaman callback, tukar code dengan token dari SSO Server:

useEffect(() => {
  const code = new URLSearchParams(window.location.search).get("code");
  if (!code) return;

  fetch("http://localhost:3000/token", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      code,
      client_id: "app1",
      client_secret: "secretapp1",
      redirect_uri: "http://localhost:3000/callback",
    }),
  })
    .then(res => res.json())
    .then(data => {
      localStorage.setItem("access_token", data.access_token);
    });
}, []);

3️⃣ Gunakan access_token tersebut untuk mengakses Laravel Resource Server: 

const token = localStorage.getItem("access_token");

fetch("http://localhost:8001/api/profile", {
  headers: {
    Authorization: `Bearer ${token}`
  }
})
  .then(res => res.json())
  .then(data => console.log(data));

🧠 Penting: Token ini adalah JWT yang ditandatangani oleh SSO Server, dan akan diverifikasi oleh Laravel Resource Server.

Laravel Resource Server

1️⃣ Install dependency untuk memverifikasi JWT:

composer require firebase/php-jwt

2️⃣ Buat middleware VerifyAccessToken.php:

<?php

namespace App\Http\Middleware;

use Closure;
use Firebase\JWT\JWT;
use Firebase\JWT\Key;
use Illuminate\Http\Request;

class VerifyAccessToken
{
    public function handle(Request $request, Closure $next)
    {
        $auth = $request->header('Authorization');
        if (!$auth || !str_starts_with($auth, 'Bearer ')) {
            return response()->json(['error' => 'Unauthorized'], 401);
        }

        $token = substr($auth, 7); // buang "Bearer "

        try {
            $jwks = json_decode(file_get_contents('http://localhost:3000/.well-known/jwks.json'), true);
            $jwk = $jwks['keys'][0];
            $publicKey = JWT::parseKeySet(['keys' => [$jwk]]);

            $decoded = JWT::decode($token, $publicKey);
            $request->merge(['user_id' => $decoded->user_id, 'username' => $decoded->username]);

        } catch (\Throwable $e) {
            return response()->json(['error' => 'Token tidak valid'], 401);
        }

        return $next($request);
    }
}

3️⃣ Tambahkan middleware di Kernel.php:

'auth.sso' => \App\Http\Middleware\VerifyAccessToken::class,

4️⃣ Gunakan route yang dilindungi oleh token:

Route::middleware('auth.sso')->get('/api/profile', function (Request $request) {
    return response()->json([
        'user_id' => $request->user_id,
        'username' => $request->username,
    ]);
});

✅ Sekarang setiap request dari React akan diverifikasi menggunakan kunci publik dari SSO Server.
